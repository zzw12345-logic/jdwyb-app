常见问题

保险什么时候生效？

接单成功后保险立即生效，直到订单完成或取消。全程自动激活，无需手动操作。

一天接多单怎么收费？

按单计费，接一单扣一单的费用。例如选择¥1.0/单的方案，一天接10单就是¥10。

什么情况可以理赔？

包括但不限于：配送途中摔伤、交通事故受伤、被客户投诉导致的罚款、恶劣天气意外等。具体以保险条款为准。

误工补贴怎么领取？

因意外受伤无法工作时，提供医院证明后，每天可领取¥100-300误工补贴，最长可领30天。
