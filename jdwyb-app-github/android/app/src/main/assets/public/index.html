关于我们

让灵活工作更有保障

接单无忧宝是专为外卖小哥、网约车司机等灵活工作者设计的智能工具。 我们深知灵活就业者面临收入波动大、缺乏保障等痛点，致力于通过技术创新， 为2亿+灵活就业者提供收入预测、风险预警和按单计费保险服务。

项目由三江学院法商学院学生团队开发，在导师指导下， 结合经济学、金融学理论，打造真正贴合灵活工作者需求的智能平台。
